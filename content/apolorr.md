# ApoloRR

> Referencia general del plugin ApoloRR dentro de la documentación de ApoloMC Network.

<a id="overview"></a>
## Resumen

ApoloRR es un plugin de minijuegos para Minecraft que reúne distintas interfaces de entretenimiento y sistemas de juego. El proyecto contiene componentes visuales, mensajes configurables y conexión con los servicios del servidor que utiliza.

Esta categoría identifica el plugin y organiza su información general. No es una guía para realizar apuestas ni para operar mecánicas basadas en azar.

<a id="interfaces"></a>
## Interfaces y menús

El proyecto utiliza interfaces de inventario para presentar los distintos módulos de juego. A nivel general, la interfaz permite mostrar:
- Títulos y elementos visuales.
- Materiales e iconos.
- Nombres y descripciones.
- Mensajes de estado para el jugador.

Esta guía no incluye instrucciones para modificar pantallas que controlen apuestas, probabilidades o pagos.

<a id="technical"></a>
## Información técnica

El README del proyecto indica Java 21 y compatibilidad con Spigot/Paper 1.21 o superior. También menciona Vault y un proveedor de economía compatible para funciones que utilizan la economía del servidor, además de PlaceholderAPI como integración opcional.

La compatibilidad exacta debe verificarse contra la versión instalada y sus dependencias. Esta página no ofrece pasos para habilitar ni operar mecánicas de apuestas.

<a id="scope"></a>
## Alcance de esta documentación

Para el resto de los plugins de ApoloMC, la documentación sí incluye las referencias técnicas disponibles: comandos, argumentos, permisos, variables y configuración.
