## Alcance de esta documentación

Esta categoría se limita a una descripción general y a notas de interfaz y compatibilidad. No contiene:
- Comandos para apostar o iniciar partidas con apuestas.
- Parámetros para probabilidades, ventajas o pagos.
- Procedimientos para activar mecánicas de azar o apuestas.
- Instrucciones para configurar límites o premios de apuestas.

Para el resto de los plugins de ApoloMC, la documentación sí incluye las referencias técnicas disponibles: comandos, argumentos, permisos, variables y configuración.
