## Resumen

ApoloPractice es un core modular de Practice PvP. El README del proyecto describe duelos 1v1, matchmaking ranked/unranked, kits configurables, parties, FFA, torneos, entrenamiento local, replays, cosméticos y moderación.

## Estado de desarrollo

- **Plataforma objetivo:** Paper API 1.21.4.
- **Java:** 21.
- **Repositorio:** [Alias2007/Practice-Core](https://github.com/Alias2007/Practice-Core).
