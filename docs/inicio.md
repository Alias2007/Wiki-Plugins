# Introducción a ApoloEvent

**ApoloEvent** es el plugin de eventos de ApoloMC Network para Minecraft Java. Esta wiki reúne la documentación disponible sobre instalación, administración, modalidades, comandos y configuración.

## Requisitos de referencia

- Java 21.
- Paper 1.21.4 como plataforma objetivo documentada.
- WorldGuard, Vault, PlaceholderAPI o UltimateClans únicamente cuando se utilicen las funciones que dependen de ellos.

Confirma siempre las versiones compatibles en el README y en los archivos del proyecto.

## Carpeta de datos

Después de iniciar el servidor con el plugin instalado, los datos se guardan en `plugins/ApoloEvent/`. Allí se encuentran configuraciones, mensajes, menús, eventos, jefes, plantillas y datos persistentes.
